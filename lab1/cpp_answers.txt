(3)

3. Numbers

(1)
short, int, long and long long are integer types with different
minimum ranges and commonly different sizes.

On 64-bit Ubuntu 22.04, the usual sizes are:
short: 2 bytes
int: 4 bytes
long: 8 bytes
long long: 8 bytes

The C++ standard does not require these exact sizes on every system.

(2)
float normally uses 32 bits and provides about 7 decimal digits
of precision. double normally uses 64 bits and provides about
15 to 16 decimal digits of precision.

After:
int i;
i = 3.14;

the value of i is 3 because conversion to int discards the
fractional part.

(3)
A signed integer type can represent negative and positive values.
An unsigned integer type represents non-negative values and uses
modular arithmetic.

Assuming an 8-bit unsigned char:
unsigned char c = -1;

the value stored in c is 255.
